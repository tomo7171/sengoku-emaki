# sengoku-emaki

ブラウザーで遊べる3D戦国シミュレーションです。このリポジトリには、公開用のゲームHTMLと画像だけを置きます。

## GitHub Pagesで公開

Settings → Pages → Build and deploymentで、Sourceを「GitHub Actions」に設定します。mainへの更新で公開用ワークフローが実行されます。

公開が完了するとPages設定画面に表示されるURLで遊べます。画像は同じURLの末尾に「preview.png」を付けて開けます。

## 遊び方

城名を選んで内政・徴兵・普請・外交・出陣を行い、次の季節へ進みます。清洲城から十城の統一を目指します。進行状況はブラウザーへ自動保存されます。

人物・拠点は1560年の史実を参考に、地形・城郭・兵数・経済はゲーム用に簡略化しています。
