# 戦国絵巻 — 天下への道

ブラウザーで遊べる3D戦国シミュレーションです。このリポジトリには、公開用のゲームHTMLと画像だけを置きます。

全国版：72勢力・95城・302人物。大名家・国人・宗教勢力と、当時の家臣・一族を収録し、織田家の清洲城を拠点に天下統一を目指します。

## GitHub Pagesで公開

Settings → Pages → Build and deploymentで、Sourceを「GitHub Actions」に設定します。mainへの更新で公開用ワークフローが実行されます。

公開が完了するとPages設定画面に表示されるURLで遊べます。画像は同じURLの末尾に「preview.png」を付けて開けます。

## 遊び方

全国地図と検索から城を選び、清洲城から天下統一を目指します。人物画像のある武将名鑑で家臣の能力と適性を確認し、足軽・弓・騎馬・鉄砲・水軍を編成します。軍議の「戦場で采配する」から部隊の武将・兵科・人数・配置を選び、3D戦場で移動・攻撃・待機・退却を指示します。野戦で敵を弱らせ、攻城戦では堀・城壁・城門を突破して本丸を攻略します。敵は守備の隙を狙い、命令直後にも攻めてきます。進行状況はブラウザーへ自動保存され、全国版v2のセーブは更新後も引き継ぎます。

地図の描画が停止した場合は自動復旧し、必要なら「3D地図を復旧」で描画を作り直せます。城の選択と進行状況は保持されます。画像はゲームHTMLに埋め込み、家紋はSVGで表示します。

全国の主要・地方大名家と実在の武将・拠点を1560年春の史実を参考に収録しています。能力値・兵科適性・攻城難易度はゲーム用の評価です。すべての国人・家臣を網羅する名簿ではありません。3D城郭は地形と曲輪を参考にした模式復元です。人物画像は主要16人物の創作画像と年齢別の共通画像を使い、実際の容貌の復元ではありません。家紋は代表紋の模式図です。琉球は当時の独立王国として区別します。
