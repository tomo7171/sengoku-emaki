# 天下布武

1560年3月の日本を舞台に、国作り・外交・調略と合戦を組み合わせて天下統一を目指す、ブラウザー用の歴史シミュレーションです。72勢力・95城・開始時の史実人物302名を基に収録し、新規開始時に勢力を選べます。

## 遊び方

開始画面の「天下を目指す大名」で全国72勢力から選び、「選んだ大名で始める」を押します。大名を選んでいる間は保存しません。保存済みのゲームがある場合も同じ選択欄を表示し、「続きから遊ぶ」で再開できます。新規開始で保存を上書きする際は確認画面を表示します。プレイ中は右上の当主を開き、「大名を選んで新しく始める」で選択画面に戻れます。

「評定・国作り」から担当武将と命令元の城を選びます。行動力は城ごとに毎月三回です。内政は対象の城、出陣は出陣元、外交・登用・捕虜処遇は選択した自領の城から消費します。他の城の行動力は減りません。城の切り替えや保存・再開では回復せず、次の月に各城三回へ回復します。落城直後の城は翌月から命令でき、籠城の指揮は行動力不要です。担当武将は今月の任務に専念します。

- **政務**：開墾・治水で石高と動員上限を増やし、商業で月収を育てます。徴兵上限は石高・人口・地形に基づきます。
- **外交・調略**：武将の政治・知略、関係値、忠誠、領国の疲弊に応じて交渉・同盟・内応を進めます。家臣への加増で結束を保てます。
- **家臣**：落城や敗走時の討死・捕縛を反映。捕虜は召し抱え・解放・処断を選べます。所属変更と生死も保存されます。十五歳未満の人物は実戦指揮や政務を担当できません。
- **軍備**：足軽・騎馬・鉄砲・弓・水軍を編制し、それぞれの部隊に武将を任命できます。初期編制には地形・地域の特徴を反映します。
- **合戦**：野戦と攻城戦で自由に配置・移動・攻撃・待機・退却を指示します。横陣・魚鱗・方円・散開、林や丘陵の伏兵を使えます。兵科相性・射程・側面・高低差・雨・水域が攻防に影響します。
- **籠城**：自領への侵攻は急報で通知されます。「籠城を指揮する」から守備側の配置と采配を行えます。未決着の侵攻がある間は季節や他の戦略命令を進められません。
- **布陣・築柵**：「プレイヤーの布陣」で部隊一覧から選び、地面のクリック／タップ・ドラッグ、または東西・南北の座標入力と「この位置へ配置」で初期配置を決めます。一覧で仮配置・未確認と配置確認済を見分け、野戦・攻城戦・籠城戦すべてで配置案を調整して「戦闘開始」で確定します。「本陣・木柵」も地面や座標で配置できます。本陣は2か所、木柵は8か所まで。施設は回転・移設・撤去でき、味方の配置範囲内で水域や建物、他の部隊との重なりを避けて設営します。設置した木柵は敵味方とも通れず、味方は迂回し、敵は迂回するか攻撃して破壊します。壊れた柵の跡は通れます。本陣は近くの味方の防御と士気を支えます。
- **兵站**：毎月の維持、出陣、戦闘中の消費を計算。戦闘中は人数に比例して兵糧を使い、不足すると士気と戦力が低下します。攻撃軍の出陣には金120貫・兵糧600石・命令1を使い、防御軍は出陣命令を消費しません。

敵勢力も城の兵力・備蓄・士気を見て侵攻し、疲弊した領国の家臣には調略を働きかけます。城門突破後の進軍、堀・城壁・曲輪・本丸の確保が攻城戦の鍵です。

地図の下の「城の接続先と進軍路」で、選択した城から直接つながる城名・旧国・所属・出陣可否を確認できます。地図では選択城の陸路を茶色の実線、海路を青色の破線で強調し、「全国の接続線」で全接続を表示します。山や海で旧来の道路模型が省略される場所も、実際の接続を表示します。「この道で出陣」から出発城を指定した軍議を開けます。

自領の城を選ぶと「周辺の自領から集兵」で、直接つながる自領の城から人数を指定して兵を移せます。元の城の守備兵と到着先の動員上限を守り、兵科別人数をそのまま移転します。出発元の命令1と人数・経路に応じた輸送兵糧を消費し、武将は移動しません。陸路では水軍を移さず、海路では水軍100人以上とその10倍までの輸送力が必要です。

## 領国経営

「評定 → 政務」には、城別の労働力・不満・工事、翌月の金銭・兵糧収支、備蓄が何か月もつかを表示します。開墾は9か月、商業は6か月の工事で、着工費に加えて毎月の工事費と完成施設の維持費が必要です。労働力や適地には上限があり、同じ工事を同時に重ねられません。資金不足では工事が中断し、徴兵しすぎると農作業の効率と収穫が下がります。

軽税・標準・重税から城ごとの政策を選びます。同じ月に何度も切り替えることはできません。重税は短期収入を増やす一方で不満が蓄積し、一揆の原因になります。救済や軽税で回復を図り、人数指定の解兵で軍維持費と農業の負担を下げられます。兵糧の購入・売却も可能ですが、売却には軍の維持用に6か月分の備蓄を残す必要があります。月ごとの台帳には収入・軍維持・工事費・施設維持・収穫・不足を記録します。

## 戦災・天候・飢饉と軍給

戦場になった城は田畑と労働力に被害が出て、その後の収穫見込みも下がります。地域と月に応じて日照り・虫害・台風・洪水を判定し、低い治水は洪水の危険を高めます。減収と食糧不足が続くと飢饉や疫病が起こり、人口と民心が低下します。民心の低下が深刻な領地では農民一揆が起こり、一向門徒の地域的な背景がある領地では一向一揆になる場合があります。これらは史実で必ず起きる事件とは分けた領国シミュレーションです。

「評定 → 政務」で城別の治水・民心・被災・飢饉・疫病・収穫損失と履歴を確認できます。「治水整備」「衛生対策」「救済」、軽税、軍縮と備蓄を組み合わせて対処します。被害と回復は継続して計算し、保存・再開だけで災害を引き直したり、同じ月に二度支払ったりしません。

兵は兵科別の月給と兵糧支給を毎月必要とし、兵数が増えるほど月収の手残りが減ります。兵科ごとの人数・俸給・糧秣と翌月の収支を表示します。9月の収穫は年一回で、毎月収穫が入る仕組みにはしていません。暦は3〜5月が春、6〜8月が夏、9〜11月が秋、12〜2月が冬です。旧セーブの現在の命令・任務は保持し、同盟の残存期間と工事を月数へ換算します。

## ターン制の合戦と持込兵糧

合戦の開始前に、出陣元・守備城にいる配下の武将を各兵科へ一人ずつ割り当て、全隊の位置をプレイヤーが確定します。同じ武将を複数の自軍部隊へ重ねて任命できず、組頭だけの部隊では開戦できません。武将が足りない場合は登用・城への配属、軍備の編制を見直すか、兵科ごとの「予備へ戻す」で出陣部隊を絞ります。予備は布陣一覧に残り、「出陣へ戻す」で復帰できます。侵攻中の城でもこの調整を使えます。野戦・攻城戦・籠城戦とも、仮配置を確認せずに開戦することはできません。

開戦後は「手動ターン」と「自動命令」を選べます。手動では部隊ごとの移動・攻撃・防御・待機を計画し、「このターンを実行」で両軍が行動します。命令を検討している間は戦闘と兵糧消費が止まります。兵科別に移動量・射程・攻撃・防御を設定し、地形・陣形・疲労が移動に影響します。敵も同じ移動・攻撃回数の制限で判断します。選択部隊には2D戦況図で水色の移動範囲と黄色の射程を表示します。

野戦・攻城戦・籠城戦とも、布陣中に各部隊の攻撃目標や移動先を設定し、「開戦後に自動進行」にチェックして開戦できます。開戦後に「自動命令」から進行を始めることもできます。攻撃命令の部隊は目標へ接近して交戦し、移動命令は目的地へ向かいます。「この部隊を待機」「この部隊を防御」で一部隊だけその場に残せ、未指定の部隊も待機します。他の味方と敵は進行を続け、待機中の部隊も被攻撃の対象となります。単一目標の攻撃と移動は、目標撃破・移動完了後に待機へ切り替わります。攻城側は「本丸制圧」で城門突破から本丸攻略までを継続できます。

部隊ごとの「第一・第二・第三目標」で、敵部隊・城門などの攻撃順序を最大三つまで設定できます。各目標の撃破後に「次の目標」「待機」「防御」「退却」を指定し、「目標の順序を設定」で確定します。待機・防御を指定した場合は残る目標を保持してその場に止まり、その部隊の「次の目標へ進む」で再開します。全体の自動進行を再開するだけでは、部隊に指定した待機は解除されません。目標をすべて達成した後は最後に指定した命令へ移り、「次の目標」の場合は待機します。ほかの部隊が先に目標を撃破した場合も、指定した順序と撃破後の命令を守ります。目標と達成状況は部隊ごとに確認できます。

自動進行中も、部隊や目標を選び直して命令を変更できます。順序を設定し直すと第一目標から新しい命令へ切り替わります。「この部隊を待機」などの個別指示や戦場での単一命令は、その部隊の目標順序を取り消して置き換えます。戦場上の移動・攻撃・防御の指示も継続命令に反映します。「自動進行を一時停止」で両軍と兵糧消費を止め、再開時は設定した命令を引き継ぎます。速度は1・2・4倍で変更でき、移動力・攻撃回数は変わりません。戦場を閉じる操作では自動進行を停止し、取り消して戻っても勝手には再開しません。自動進行は各ターンの命令・兵糧・障害物・戦後処理と同じ規則を使います。


出陣の軍議と籠城の軍議で、合戦に用意する兵糧の数量を指定できます。15・30・60分を目安にするボタンと直接入力を用意し、予想消費と領国に残す備蓄を表示します。攻撃軍の準備費600石は持込分と別に必要です。合流する同盟軍も消費人数に含め、戦場で兵が減れば消費も減ります。合戦中に領国の在庫から補充はせず、枯渇すると士気低下に加え、攻撃力と疲労に影響します。実際に使った兵糧だけを戦後に精算し、未使用分は備蓄へ戻します。

部隊には「通常」「迎撃」「強行・突撃」「休息」の構えがあります。強行と突撃は移動・攻撃に有利ですが疲労と隊列の乱れを招き、迎撃の正面へ騎馬で突っ込むと不利です。戦闘中の陣形変更も隊列を乱します。休息は敵から離れた場所で回復に使い、接敵中に休ませると危険です。味方を挟んだ射撃は射線を遮り、止まって構えた弓・鉄砲は安定します。継続的な射撃は敵を制圧し、側背面攻撃や歩兵と射撃の連携も損害に反映します。敵も同じ疲労・休息・迎撃の規則で判断します。

## 家臣の補充・一門と家督

「家臣」の登用候補一覧で、毎月八人の在地人材と仕官を求める浪人を比較できます。肖像・年齢・出自・統率・武勇・知略・政治・費用をまとめて表示し、各行の登用ボタンで選びます。登用後も残る候補の名前と能力を保持し、選択した城へ配属します。通常は金150貫・その城の命令1を使い、毎月2人まで。成人武将が一人もいない場合は金・命令不要の救済登用で立て直せます。死亡済みの武将は復活させません。

担当者の欄では任務中の武将を選べず、任務を命じた後は未任務の人物へ切り替わります。全員が任務中または成人不在の場合、奉行衆が能力を抑えた内政・徴兵・褒賞・捕虜解放を通常の費用と命令で代行します。外交・調略・合戦の武将にはなりません。「次の月へ」で命令と担当武将の任務を回復できます。

「家臣」の「武将の城配置」で、配下の武将を城別の一覧から選べます。所属城での絞り込み、名前検索、能力順、共通の配属先とまとめ配置を使い、配下の武将を自領の城へ配置できます。武将と配置先をプレイヤーが指定し、現在の所属城の命令を1使います。任務中の武将は移せません。移動した武将は元の城の指揮官から外れ、配置先の既存の指揮官は維持します。配置後の所属城は保存・再開でも保持します。城代（総大将）は、その城に配置されている活動中の成人武将からだけ任命できます。他城や未配属の武将を選んで自動的に移すことはできません。先に城配置を命じてから任命してください。

「一門・継承」では世継ぎ・養子・後見人を指定できます。当主死亡時は指定の世継ぎを優先し、幼君や捕縛中の当主を成人の後見人が支えます。当主の名前も継承に追従します。

織田信忠・武田勝頼・伊達政宗・徳川秀忠などは史実の生年と親の生存・所属に応じて登場し、男子は十五歳で元服して政務・合戦を担当します。開始時点で出生済みの子も移行時に補います。ゲーム内で生まれる架空の子は史実人物と区別し、男子は一門、女子は姫として登録します。姫の婚姻は双方十八歳以上とし、両家と配偶者が健在な間は婚姻同盟を更新します。

敗戦時は退却を基本とし、通常の損害では討死を判定しません。敗軍の損害率が50%以上で討死0.5%、75%以上で1%となります。捕縛や処断は別の結果です。旧セーブの領地・商業・武将の生死を保持し、新しい家中データを追加します。

武将の生年はシナリオの史実データと出生表に合わせ、生年不詳の人物には推定と分かる設定を与えます。自然寿命と世代交代を導入し、二百歳を超える生存者が残っている旧セーブも修正します。死亡年・死因・享年を保存し、故人の年齢は季節が進んでも増えません。家康・秀吉・前田利家など自然死とされる主要人物は史実の没年を基準とし、他は成人の多くが六十〜八十歳前後となるゲーム用の寿命モデルです。討死・処刑などの史実の死を強制せず、合戦や処遇による分岐を保ちます。当時の出生時平均余命を成人武将全員の寿命にはしていません。

史実の出生表は前田利長・池田輝政・本多正純・酒井家次・細川忠興など家臣の子にも対応します。史実の生年に親が生存・在籍する場合に登場し、十五歳で元服します。過去の人物を何百年も遅れて誕生させたり、戦死した親を復活させたりしません。ゲーム中の架空の一門と史実人物は区別して表示します。

合戦後は「武将の安否と捕虜の処遇」で、参加した武将の生還・退却・討死・捕虜を個別に確認できます。落城時に城内で捕らえられた武将も記録し、その画面から召し抱え・解放・処断を選べます。処断は確認を挟み、処遇の履歴は合戦時の安否と別に保存します。天下統一後も命令を消費せずに捕虜を処遇できます。詳細を保存していない旧形式の合戦では、後年の病没を討死と推測せず「記録なし」と表示します。

## 同盟国との援軍

「外交」で同盟国との婚姻、恭順交渉、同盟破棄を選べます。婚姻は自家の姫と実際に婚姻できる相手を一人ずつ指定し、十八歳未満・既婚・近親などの対象は選べません。成人前の場合は誕生・成人を待つ理由を表示します。「一門・継承」でも同じ候補を使います。婚姻には金300貫と指定城の命令1が必要です。

恭順交渉は両家の兵力・友好・威信と使者の能力が成否に影響し、金400貫と命令1を使います。成立すると相手の城・家臣は相手に残したまま、相互不可侵と余剰資源からの月次貢納を設定します。城の併合や天下統一の領地数には加えません。同盟破棄は影響を確認してから確定し、指定城の命令1・友好−40・威信−10を伴います。婚姻同盟や恭順の盟約も破棄でき、婚姻同盟が翌月に勝手に復活することはありません。婚姻の家族記録そのものは残ります。

同盟国が他家へ侵攻するときも、侵攻を受けたときも、交戦が決着する前に援軍要請が届きます。「援軍要請を確認」、または評定の「外交」から、派兵元の自領の城と人数を指定して派兵するか、要請を拒否します。プレイヤーが返答するまで季節と戦略命令は進みません。自動で自軍を派遣することはありません。

派兵は出兵元の城の命令1・金120貫と、人数・戦い方に応じた兵糧を使い、守備兵を残せる人数だけ送れます。自領・同盟領を通る経路が必要で、海路には水軍と輸送力が必要です。援軍は同盟国の戦力に加算され、戦後に損失・帰還兵と戦況を報告し、生き残った兵を派兵元へ戻します。派兵で友好+5、要請の拒否で友好−15。既に交戦が不可能になった要請は、友好度や資源を失わず終了できます。

こちらの出陣では軍議の「同盟国へ援軍を要請」、籠城では急報欄の同名ボタンから、同盟国の城と人数を選べます。友好・兵力・経路・兵站が条件を満たすと、同盟国の兵を実際に確保して合流します。「戦場で采配する」から出陣すると、援軍を自軍と分けた部隊として配置し、陣形・移動・攻撃を指示できます。援軍の将・兵科・人数は同盟国の編制を維持します。損失は自軍と別に精算し、生還兵は同盟国へ帰還します。出陣前に要請を取り消す場合も兵は帰還しますが、消費した出陣費用・兵糧は戻りません。

## 地図・人物・合戦の表示

旧国68国と蝦夷・琉球を収録。旧国名は拡大に応じて重なりを避けて表示し、「旧国名」で切り替えられます。「勢力」では72勢力を異なる色で表示し、凡例で勢力名を確認できます。塗り分けは城の位置を基にした勢力圏の目安で、歴史上の国境ではありません。

架空の登用武将・一門には数字の接尾辞を使わず、漢字の姓名を付けます。旧セーブの数字付き架空名も人物ID・能力・親子関係を維持して修正します。

武将の肖像は、肌や髪、甲冑の質感と光を表現した写実的な創作画像です。開始時の武将には人物ごとに異なる画像を割り当て、主要な大名には大きな専用画像を用意しています。幼子・姫などは年齢と性別に応じた画像に切り替えます。誕生する架空人物の画像には年齢別の素材を用いるため、顔立ちが似る場合があります。画像はゲーム内に同梱し、プレイ中に外部画像サービスへ接続しません。実際の容貌を確定するものではありません。

合戦はWebGLを使わない「2D戦況図」を標準にします。実際の部隊・兵数・城門・曲輪・地形・木柵を描き、クリック／タップとドラッグによる布陣・移動・攻撃、拡大縮小、全域表示を行えます。「3D表示」へ切り替えても戦況と兵糧は維持し、3Dの初期化や描画が失敗した場合は自動で2Dへ戻します。表示の選択はブラウザーに保存します。

落城・野戦決着後は、画面上部に勝敗と戦後処理の進捗を表示します。長い合戦の記録確認を分割して画面の応答を保ち、領地・損失・兵糧・武将の処遇を確定してから「結果を確認して評定へ」で戻れます。処理に失敗した場合は理由と「戦果の反映を再試行」を表示し、戦果を保持して二重精算を防ぎます。再試行しても完了しない場合は、確認のうえ「戦果を反映せず戻る」から合戦開始前の状態へ戻れます。

3Dの合戦では地面の質感・照明・土煙・鉄砲の発砲光と煙を表現。「臨場視点」「上から見る」で視点を切り替えられます。端末で動きを抑える設定を使っている場合は発砲光と土煙を抑えます。3D地図が停止した場合は「3D地図を復旧」で描き直せます。

合戦の描画には天候に応じた空からの環境反射、日光と柔らかい影、地面の不規則な色むら・凹凸、樹皮・葉・水面の質感を加えています。杉・松・広葉樹・草には写真調の創作素材を組み込み、枝葉と林床の茂み、戦場の外側に広がる山並みを描きます。兵の甲冑は鉄と漆の色を基調に、細部と個体差を描きます。実写風の質感を目指した操作可能な3Dで、録画映像ではありません。

合戦で実際に配置・移動できる戦場を前版の面積十倍へ拡張しています（当初の戦場の四十倍）。平野・盆地・丘陵・山地・沿岸・北方の沿岸・琉球の七種類を基に、城ごとに縦横比、山谷、蛇行する川、岬と入り江、田畑と集落の配置を変えます。「戦場全体」で全景を確認でき、城郭の細かな地形は広域化しても保持します。家屋と深い川は通行できず、部隊は街路・橋・浅瀬へ迂回します。水田や浅瀬では行軍が遅くなり、町村は射撃の被害を軽減します。海域と陸地は共通の地形データで判定し、集落や田畑は陸側へ置きます。城の周辺地形・町村の配置はゲーム用の近似で、実在の城下を測量復元したものではありません。

両軍の初期配置は大名家・地域・地形・兵科で変化します。実際に編制された兵数を保ち、騎馬を側面、弓や鉄砲を後方や高所へ配置します。攻城側と籠城側でも陣を変え、守備兵は既存の曲輪を使います。合戦準備に自軍・敵軍の陣名を表示し、プレイヤーは自軍の配置を自由に調整できます。

野戦には実写風の創作情景画像を表示し、「情景を大きく見る」で確認できます。現在の兵の位置や勝敗は、その下の操作可能な戦況図で確認します。情景画像は実写動画や戦闘の再現映像ではありません。

攻城戦・籠城戦では写実的な城郭の創作復元画像を表示し、「城の画像を大きく見る」で全体を確認できます。七尾城・稲葉山城・小田原城・清洲城に専用画像を用意し、その他の城は山城・平山城・平城・海辺の城の参考復元図と明記します。3Dの城にも木材・石垣・土塁・漆喰・屋根の質感を加えています。画像とテクスチャは同梱しており、外部接続は不要です。発掘図面を照合した完全復元や現地写真ではありません。

戦場内の3D城郭は、主郭館を二層（条件を満たす城は三層）、控え館を長屋、物見櫓を板壁で囲った二重櫓として描画します。城門は太柱・控柱・石台と上階を備える櫓門とし、囲いには瓦笠木・狭間・控えを備えた厚い土塀や漆喰塀を使います。曲輪の法面には接地した土塁、大小不揃いの野面石、長短交互の隅角石を加え、石・締固め土・漆喰に専用の写実的な表面画像を適用しています。既存地形と城郭の区画を基にした創作模型で、1560年の発掘復元を確定するものではありません。

「3D城郭を見る」または「城郭を見る」で城全体へ、「城門に寄る」で門の近くへ視点を切り替えます。本丸・二の丸・三の丸はゲーム内の主郭・前郭の関係に応じて整理した区分で、実際に描画する曲輪数まで表示し、支郭は別に扱います。各曲輪のボタンで注視でき、元の区画名はボタンのツールチップに保持しています。「曲輪名を隠す／表示」で名前を切り替え、「視点を戻す」で初期視点へ、「戦場全体」で広域の全景へ切り替えます。門が破れると扉が倒れ、既存の通路幅を保って部隊が進軍します。

七尾城の三つの城門と曲輪の間では、進軍路の幅を含めて城壁の通路を確保します。破った城門の先で見えない壁に停止せず、本丸を占領して落城させられます。敵兵の全滅だけで無条件に城を奪うのではなく、本丸まで進軍する必要があります。

## 史実とゲーム内の分岐

「年代記」は鉄砲伝来（1543年）などの既往史と、1560年以降の歴史イベントを記録します。全14件の年代イベントを収録し、登場勢力・人物の生存や領有条件に応じて効果を反映します。1560年開始なので鉄砲伝来を開始後の出来事として再発させません。

桶狭間・川中島・清洲同盟・楽市・上洛・長篠・安土城・本能寺などの史実を参照しますが、プレイで変化した人物の生死や領土を史実に戻す処理は行いません。長篠の「三段撃ち」を確定史実として扱いません。

武将・旧国・主要拠点は1560年春を基準としています。すべての国人や家臣を網羅する名簿ではありません。石高・兵数・能力・兵科相性はゲーム用の推計、城郭は特徴を反映した模式復元、肖像は個人ごとの創作画です。実際の容貌や城郭の発掘図面の完全復元ではありません。史料参照先のURLは実装時にアクセス制限があり、内容の再閲覧・照合は未完了です。琉球は当時の独立王国として区別します。

## ローカルで動作確認

追加のビルドや実行用パッケージは不要です。Python 3で次を実行し、ローカルHTTPサーバーをWebGL対応ブラウザーで開きます。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Node.jsの標準テストで、内政・交渉・捕虜・歴史イベント・兵站、および実際のゲームエンジンを用いた攻城・防衛・伏兵・陣形・記録検証を確認できます。

```sh
node --test tests/*.spec.js
```

進行はブラウザーのローカルストレージへ自動保存します。既存の全国版v2セーブも読み込めます。新しい内政・忠誠・年代記の項目は初回読み込み時に補われます。
