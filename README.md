# 戦国絵巻 — 天下への道

ブラウザーで遊べる3D戦国シミュレーションです。このリポジトリには、公開用のゲームHTMLと画像だけを置きます。

全国版：72勢力・95城・302人物。大名家・国人・宗教勢力と、当時の家臣・一族を収録し、織田家の清洲城を拠点に天下統一を目指します。

## GitHub Pagesで公開

Settings → Pages → Build and deploymentで、Sourceを「GitHub Actions」に設定します。mainへの更新で公開用ワークフローが実行されます。

公開が完了するとPages設定画面に表示されるURLで遊べます。画像は同じURLの末尾に「preview.png」を付けて開けます。

## 遊び方

全国地図と検索から城を選び、清洲城から天下統一を目指します。武将名鑑で家臣の能力と適性を確認し、足軽・弓・騎馬・鉄砲・水軍を編成します。野戦で敵を弱らせ、3D攻城戦で城を攻略します。敵は守備の隙を狙い、命令直後にも攻めてきます。進行状況はブラウザーへ自動保存され、旧地方版のセーブは別に保持されます。

全国の主要・地方大名家と実在の武将・拠点を1560年春の史実を参考に収録しています。能力値・兵科適性・攻城難易度はゲーム用の評価です。すべての国人・家臣を網羅する名簿ではありません。3D城郭・部隊は特徴を表現したモデルで、合戦は戦略計算に基づく戦況の再現です。琉球は当時の独立王国として区別します。

日本列島の海岸線はNatural Earthのパブリックドメイン地理データを簡略化して使用しています。https://www.naturalearthdata.com/about/terms-of-use/
